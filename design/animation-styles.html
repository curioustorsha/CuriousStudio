Animation style samples*

Five looks, each mocked up for both video series. Every sample is a live 6-second loop built the same way Remotion builds a frame: shapes plus easing curves, nothing realistic. Click any phone to see it bigger.

What I'd pick

  • How It Scales: A, Isometric 2.5D. System design is about things in space: servers, queues, warehouses, trains. Isometric turns each one into a tiny world that is easy to read at a glance. You already have an isometric kit in video/src/engine/iso.tsx. Borrow D (Blueprint) for the moment the full architecture is revealed.
  • Claude Lab: B, Flat bold morphs, with C's glass cards for screens. Claude Lab explains ideas through metaphors, and one shape morphing into the next (card → agent → app) is the smoothest way to show that. When a terminal or app window has to appear, use the frosted-glass card from C so it looks like a product, not a cartoon.
  • Use the same motion rules on both series so they still feel like one channel: the same yellow accent, the same fonts, the same easing curves.

What makes motion feel premium (for any style)

  • Use one family of easing curves everywhere: things enter fast and settle softly (expo-out). Moves ease in and out. Springs overshoot only 5–8%, never a cartoon bounce.
  • Stagger related items by 2–4 frames instead of moving them all at once.
  • Never hold a frozen frame. A slow 2–3% camera push and small ambient motion (packets flowing, background blobs drifting) keep it alive.
  • Use one accent color per frame, and start each animation on the word that names it in the voiceover.
  • Render at 60 fps. Shorts, Reels and TikTok all play it, and it is the cheapest upgrade in smoothness you can get.
